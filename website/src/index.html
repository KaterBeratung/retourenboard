06 / Gut zu wissen

Noch etwas offen?

Gut zu wissen.

Ist das eine Cloud-Anwendung?

retourenboard wird auf deinem eigenen Server betrieben. Du richtest den Zugang für dein Team ein und kümmerst dich um den Betrieb. Diese Produktseite ist unabhängig von deiner Installation.

Wer kann meine Daten sehen?

Bestandsdaten und Dateianhänge sind in der Anwendung nur nach Anmeldung verfügbar. Der erste Account wird Administrator; weitere Konten legt ein Admin an. Berechtigungen lassen sich je Konto anpassen.

Kann ich bestehende Daten übernehmen?

Ja, über den CSV-Import. Vorlagen und Importprofile helfen bei der Zuordnung deiner Spalten. Produkte und Retouren lassen sich auch als CSV exportieren.

Kann ich das Board zuerst ausprobieren?

Der Installer bietet --test für einen temporären Testbetrieb. Dabei werden keine vorhandenen Konten oder Daten verwendet. Mit Strg+C endet der Test und die Testdaten werden entfernt.

Wie funktionieren Updates?

Der Installer kann eine bestehende Installation aktualisieren. Auf unterstützten Linuxinstallationen gibt es außerdem einen Versionscheck und einen Updater im Adminbereich. Updates werden bewusst gestartet; Daten und Anhänge bleiben erhalten. Details stehen in der Projektdokumentation.
